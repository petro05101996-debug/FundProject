# Investment Scenario Lab Engine (v1)

Ядро делает:
- считает сценарии по пользовательским вводным;
- считает доходность до/после комиссий и налогов;
- считает реальную доходность с учётом инфляции;
- считает ликвидность;
- считает концентрацию;
- считает стресс-сценарии;
- считает риск-флаги;
- считает балл соответствия пользовательским ограничениям;
- формирует данные для отчёта.

Ядро не делает:
- не прогнозирует рынок;
- не подбирает инструменты;
- не даёт инвестиционных рекомендаций;
- не исполняет сделки;
- не подключается к брокеру;
- не гарантирует доходность;
- не делает точный налоговый расчёт;
- не использует реальные котировки.
